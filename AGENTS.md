# AGENTS.md

Сайт-портфолио разработчика ПО: автоматизация и AI-агенты. Весь сайт — один файл `index.html` (источник); остальные страницы генерирует `tools/prerender.mjs` (см. «SEO / GEO и пререндер»).

## Стек и запуск

- Чистые HTML + CSS + vanilla JS в одном файле. Сборки, зависимостей, `package.json` и тестов нет. Единственный серверный код — `api/contact.js` (Vercel Function формы, без зависимостей). Инструмент разработчика — `tools/prerender.mjs` (Node, без зависимостей), на Vercel он не запускается: сгенерированные файлы коммитятся.
- Внешних ресурсов нет. Шрифты (Tektur, Onest, JetBrains Mono) лежат в `fonts/` — переменные woff2, подмножества latin, latin-ext, cyrillic, cyrillic-ext; `@font-face` в блоке `FONTS` в начале CSS. Шрифты с CDN не подключать (DSGVO).
- Картинки лежат в `img/`, новые класть в WebP (оригиналы JPG/PNG/GIF в репозитории исключены из деплоя в `.vercelignore`). Пути в `index.html` относительные (`img/…`, `fonts/…`), без ведущего `/`: так сайт открывается и через `file://`. В страницах на уровень глубже (`en/`, `ru/`, `impressum/`, `datenschutz/`) пререндер сам дописывает `../` (`upOne`). Превью ссылки для LinkedIn и соцсетей — `img/og.jpg` (1200×627, скриншот слайда `about` на немецком), мета-теги Open Graph генерирует пререндер. Поменялся первый слайд или домен — переснять картинку (headless Chrome, 1200×627, светлая тема, после анимации загрузки) и поправить `SITE` в `tools/prerender.mjs`.
- Статистика — Vercel Web Analytics: два `<script>` в конце `<head>`, скрипт грузится с того же домена (`/_vercel/insights/script.js`), без cookie. Включается в панели Vercel (Project → Analytics). Под `python -m http.server` скрипт отдаёт 404 — это нормально. Описана в разделе 6 Datenschutzerklärung.
- Запуск: `python -m http.server 8123`. Конфигурация для Claude Code — `.claude/launch.json`. Можно открыть и `index.html` напрямую (`file://`): картинки, видео и переключение языка работают (язык меняется на месте, без смены адреса), не работают только форма (`/api/contact`) и аналитика. Проверять на ширине десктопа и 375px, в светлой и тёмной теме.
- Держать всё в одном файле. Фреймворки и сборку не вводить без запроса.
- Деплой: `vercel.json` — редирект `www.profidev.de` → `profidev.de` и кэш для `/fonts/` и `/img/`; `.vercelignore` — что не публикуется (резюме `Lebenslauf_*.pdf`, `AGENTS.md`, `.claude/`, `tools/`, оригиналы картинок). Резюме ещё и в `.gitignore`.

## Устройство `index.html`

Файл поделён комментариями-маркерами `/* ==== NAME ==== */`. Ищи по ним, номера строк быстро устаревают.

- **CSS**: `TOKENS` → фон → `NAV` → `HUD` → `STAGE / SLIDES` → по секции на каждый слайд → `SHUTTER TRANSITION` → `MODALS` → `RESPONSIVE` (1360 / 1100 / 860 / 520px).
- **HTML**: в `<head>` блок `<!-- prerender:head -->…<!-- /prerender:head -->` (title, description, canonical, hreflang, Open Graph, JSON-LD) — его целиком пишет пререндер, руками не править. Шапка с меню (`#menu`, панель ссылок `<a href="#id" data-go>` с бегунком `#menuThumb`; ≤1100px вместо неё выпадающий список `#navDd`) и панелью настроек (`.prefs`: выпадающие списки языка `#lang` и темы `#theme`, тема хранится в `localStorage['pf-theme']`), HUD, `<main class="stage">` с шестью `<section class="slide">`, шторка перехода, модалки проекта и сертификата, кастомный курсор.
- **JS** (IIFE в конце файла): `I18N` → `TEST DATA` → `KNOWLEDGE DATA` → геометрия шестерёнок и spin engine → фон (gears, circuits, binary) → `SLIDES & NAV` → `KNOWLEDGE GRAPH` → сертификаты → карусель проектов → модалки → форма → язык → `INIT`.

## Слайды

Это не прокручиваемая страница, а презентация. Слайды по порядку:
`0 about`, `1 experience`, `2 skills`, `3 certs`, `4 projects`, `5 contact`.

- Переход идёт через `goTo(i)`: кнопки пейджера внизу, клавиши, меню или любой элемент с `data-go="i"`. Индекс пишется в URL-хэш (`#projects`).
- Индексы слайдов зашиты в нескольких местах: `data-go`, ключи `nav.N` и `word.N`, статичные счётчики `ghost-num` в разметке, пункты меню в `#menu` и `#navDd`. Если добавляешь или переставляешь слайд, обнови все эти места.
- Меню — панель переключаемых ссылок (`<a href="#about">`, чтобы краулеры видели структуру; клик перехватывает общий обработчик `[data-go]`). ≤1360px кнопки ужимаются, ≤1100px панель заменяется выпадающим списком слева. Добавляешь пункт — проверь ширину на 1101px на всех трёх языках (немецкий самый длинный).

## i18n: de (основной) / en / ru

- Весь видимый текст берётся из объекта `I18N` через атрибуты `data-i18n`, `data-i18n-aria`, `data-i18n-ph` и `data-i18n-alt`. Текст в разметке `index.html` — немецкий, его вписывает пререндер; руками его не правят — правят `I18N` и запускают пререндер.
- **Новый ключ добавляй сразу во все три языка.** Если ключа нет, `t()` берёт русскую версию, а если нет и её — показывает сам ключ.
- У каждого языка свой адрес: `/` — немецкий (и `x-default`), `/en/`, `/ru/`. Язык страницы = `<html lang>` (`PAGE_LANG`). Язык браузера **не** используется, иначе Google (браузер `en-US`) проиндексирует `/` по-английски. Выбор в переключателе сохраняется в `localStorage['pf-lang']` и применяется только на `/`; на `/en/` и `/ru/` всегда решает адрес. Переключатель меняет язык на месте и путь через `history.replaceState` (`LANG_PATH`), `applyLang` обновляет `document.title` и `meta description` из ключей `meta.title` / `meta.desc`.

## SEO / GEO и пререндер

- Поисковики и AI-краулеры (GPTBot, ClaudeBot, PerplexityBot) JS не выполняют, поэтому весь текст должен лежать в HTML. **После правки `I18N`, данных (`PROJECTS`, `CERTS`, `JOBS`, `KN_*`) или `LEGAL` запусти `node tools/prerender.mjs`**; `node tools/prerender.mjs --check` — проверка без записи (код 1, если что-то устарело). Скрипт идемпотентен.
- Что делает: вычисляет блоки `I18N … GEAR GEOMETRY` и `LEGAL` из `index.html` (с заглушками DOM) и пишет:
  - в `index.html` (de) и в сгенерированные `en/index.html`, `ru/index.html`: `<html lang>`, блок `prerender:head`, текст во все элементы с `data-i18n*` между `<header class="nav">` и `</main>` (модалки и шторку не трогает; подсказки ошибок формы `*Err` оставляет пустыми), итоговые числа `data-count`;
  - статичные снимки между маркерами `<!-- prerender:tl|knList|certGal|carousel -->` внутри контейнеров, которые JS при загрузке перезаписывает интерактивной версией (без `<img>`, чтобы не было лишних загрузок; шторка `boot` закрывает экран до замены);
  - `impressum/index.html`, `datenschutz/index.html` (из `LEGAL`, стили — блоки FONTS и TOKENS + правила `.lg`), `sitemap.xml` (с `xhtml:link` hreflang), `llms.txt` (на немецком).
- JSON-LD (`@graph`): `WebSite`, `ProfilePage`, `Person` (адрес как в Impressum, `sameAs`, `knowsAbout` из хабов и технологий `KN_NODES`, `alumniOf` из `JOBS`, `hasCredential` из `CERTS`), `ProfessionalService` (услуги `svc.N`), `CreativeWork` на каждый настоящий проект, `FAQPage` из `faq.*`. Константы (адрес, ссылки профилей, домен) — в начале `tools/prerender.mjs`.
- `en/`, `ru/`, `impressum/`, `datenschutz/`, `sitemap.xml`, `llms.txt` руками не править. `robots.txt` — ручной, разрешает всех, включая AI-ботов, закрывает `/api/`.
- Заголовки: `h1` — имя, затем `h2` (скрытый `svc.title` над услугами, заголовки слайдов, FAQ) и `h3`.

## Контент

- `CERTS` — настоящие данные, раздел сертификатов готов. Изображения лежат в `img/certs/` (WebP). В галерее картинка ждёт в `data-src` и подставляется при первом входе на слайд `certs` (`certLoad()` в `enterSlide`): слайды лежат друг на друге, `loading="lazy"` не сработал бы. `alt` — название сертификата (`data-i18n-alt`). Поля каждого сертификата:
  - `w`/`h` — размер картинки, по ним считаются ориентация и раскладка галереи;
  - `date` — `YYYY-MM-DD` или `YYYY-MM`, форматируется через `Intl` под язык сайта;
  - `verify` — ссылка на онлайн-проверку, если она есть;
  - `no` — номер/ID сертификата, без него строка ID в панели скрыта;
  - `minor: true` — второстепенный сертификат: маленькая карточка, на десктопе третья колонка сверху вниз (общая ширина, `layoutCerts`), ≤860px — горизонтальная полоса с прокруткой под галереей;
  - название и описание — i18n-ключи `cert.<key>` и `cert.<key>.i`.
- Граф знаний (слайд `skills`) — черновик, собран по сертификатам и программе курса ITCareerHub/Beam «KI-Automatisierung»; владелец будет править. Данные в блоке `KNOWLEDGE DATA`:
  - `KN_CATS` — разделы (по ним раскладываются области облака), `KN_ORDER` — их порядок в таблице. Цвет раздела — токен `--k-<key>` (RGB-тройка, задан в `:root` и в обоих тёмных блоках), название — `kn.cat.<key>`;
  - `KN_NODES` — узлы `{ id, cat, name?, hub? }`. `name` — подпись без перевода (названия технологий); без `name` подпись берётся из `kn.n.<id>` во всех трёх языках. `hub: true` — центральный узел раздела: подпись видна всегда и крупнее, в таблице идёт первым. Все узлы — одинаковые точки, размер зависит от числа связей;
  - `KN_LINKS` — строки `'a: b c d'`, связь двусторонняя. Опечатка в id — предупреждение в консоли. Размер узла и порядок в таблице зависят от числа связей;
  - раскладка — детерминированная симуляция при загрузке: все узлы лежат на поверхности сферы и равномерно отталкиваются друг от друга, связи слабо стягивают соседей, разделы тянутся к своим областям. При правке данных облако меняет форму, но при каждом открытии выглядит одинаково.
- Движок графа — canvas 2D со своей перспективной проекцией, без библиотек. Рисуется только когда слайд активен (`kgFrame` из главного цикла). Список в таблице и карточка узла строятся из данных через `innerHTML` с экранированием `esc()`.
- `JOBS` (слайд `experience`, таймлайн) — настоящие места работы в обратном порядке, от текущей (фриланс) к первой: `{ key, name, parent?, logo?, icon?, from, now?, tags }`. `name`/`parent` — без перевода, описание — `job.<key>` во всех трёх языках, `from` — год начала (без него показывается заглушка `job.yyyy`). Логотип — файл в `img/logos/`; `icon` — ключ inline-иконки из `JOB_ICONS` в цветах темы (так сделан фриланс); без обоих — пустая пунктирная плашка. Знак AixPano — SVG с вшитым PNG, обрезанный `viewBox` и `clipPath` из вытянутого логотипа с их сайта. Должность — `job.<key>.r` (у фриланса вместо неё `job.freeC`). `tags` — массив технологий без перевода; элемент `'#x'` — переводимая плашка из ключа `job.t.x`.
  - Раскладка: на десктопе сетка 14 колонок, работа `i` начинается с колонки `2i+1` и занимает 4, чётные — над линией, нечётные — под ней; год стоит у узла на линии. ≤860px линия вертикальная по центру, карточки чередуются слева/справа (`--r`), год — внутри карточки. Новую работу добавляй в начало массива; седьмая — расширь сетку (`repeat(14,…)` → 16). В начале линии — наконечник `.tl-arrow` (время идёт к текущей работе: влево, ≤860px вверх), блик `busflow` бежит в ту же сторону.
- `PROJECTS` — все семь проектов настоящие (drafta, Mira, Spirit FairPlate Shop, Benefita, Product Card AI, Gastronomie AI, Lingvy). Код для тестовых проектов без `key` (общие заглушки `proj.title`, `pm.*`) оставлен. У настоящего проекта есть `key` и `name` (название без перевода; если его нет, название берётся из `prj.<key>.t`), тексты берутся из ключей `prj.<key>.d` (карточка), `.lead`, `.p0`–`.p2` (вкладки модалки) и `.s<N>` (alt кадров) во всех трёх языках. `shots` — кадры `{ src, w, h, anim? }` из `img/projects/`: первый идёт в карточку, все вместе — в миниатюры модалки. `anim` — тяжёлая анимация (анимированный WebP, `*-anim.webp`): сначала показывается статичный `src`, а `playAnims()` подменяет его на анимацию, когда открыт слайд проектов или кадр в модалке (при `prefers-reduced-motion` остаётся статичный кадр). ≤860px модалка проекта занимает весь экран (`.pm .m-panel`, без скруглений; радиус маски раскрытия `openModal` берёт из CSS). Клик по большому кадру в модалке открывает полноэкранный просмотр `#zoomer` (блок `SHOT ZOOM` в CSS и JS): зум колесом, кнопками, `+`/`-`/`0`, двойным кликом и щипком, перетаскивание, Esc закрывает только его. `url` — ссылка на живой проект, показывается кнопкой `pm.site` («Открыть сайт»). Метрики и кнопки демо/кода у настоящих проектов скрыты, пока для них нет данных; блок «Стек» скрыт, если `tags` пустой. Тестовые проекты берут общие заглушки (`proj.title`, `pm.*`).
- Фото в hero уже настоящее: `img/photo.webp` (660×660), `alt` — ключ `hero.photo`. Кадрирование в круг задаётся через `object-position` в правиле `.photo img`.

## Дизайн-конвенции

- Цвета — только токены `:root`. Тёмная тема задана **дважды**: `@media (prefers-color-scheme: dark)` и `:root[data-theme="dark"]`. Меняешь одну — меняй обе.
- Мотив шестерёнок: `data-gear="<зубья>"` рисует шестерёнку, `data-spin="<скорость>"` её вращает, `kick(el, deg)` и `boost(dir)` дают импульс.
- Анимация появления: обёртка с `data-a="up|left|right|scale|clip|fade"` и задержкой `style="--d:N"`.
- Учитывать `prefers-reduced-motion`: флаг `RM` в JS и отдельный media-блок в CSS.
- Не ломать навигацию с клавиатуры (стрелки, PageUp/Down, Home/End, Esc) и `aria-*` атрибуты.
- Колесо и свайп слайды **не** листают: они только прокручивают содержимое слайда и внутренние блоки, а по canvas графа свайп вращает облако. Горизонтальное колесо над каруселью проектов листает карточки.
- Листание — пейджер `#pager` в левом нижнем углу (внутри полосы `#bar`, рядом со ссылками `.legal`): кнопки `#pgPrev` / `#pgNext` с номером и названием соседнего слайда (`nav.N`) и стрелками влево / вправо. `setPager(i)` ставит им `data-go` и `aria-label` (`pg.prev` / `pg.next`), вызывается из `setActiveUI` и при смене языка. На первом и последнем слайде лишняя кнопка `disabled` и убрана (`display:none`). ≤520px номера скрыты, длинные названия обрезаются, чтобы пейджер не был шире экрана.
