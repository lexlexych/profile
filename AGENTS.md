# AGENTS.md

Сайт-портфолио разработчика ПО: автоматизация и AI-агенты. Весь сайт — один файл `index.html`.

## Стек и запуск

- Чистые HTML + CSS + vanilla JS в одном файле. Сборки, зависимостей, `package.json` и тестов нет. Единственный серверный код — `api/contact.js` (Vercel Function формы, без зависимостей).
- Внешнее только Google Fonts (Tektur, Onest, JetBrains Mono).
- Картинки лежат в `img/`.
- Запуск: `python -m http.server 8123`. Конфигурация для Claude Code — `.claude/launch.json`. Если открыть файл напрямую через `file://`, картинки по относительным путям могут не загрузиться. Проверять на ширине десктопа и 375px, в светлой и тёмной теме.
- Держать всё в одном файле. Фреймворки и сборку не вводить без запроса.

## Устройство `index.html`

Файл поделён комментариями-маркерами `/* ==== NAME ==== */`. Ищи по ним, номера строк быстро устаревают.

- **CSS**: `TOKENS` → фон → `NAV` → `HUD` → `STAGE / SLIDES` → по секции на каждый слайд → `SHUTTER TRANSITION` → `MODALS` → `RESPONSIVE` (1360 / 1100 / 860 / 520px).
- **HTML**: шапка с меню (`#menu`, панель кнопок с бегунком `#menuThumb`; ≤1100px вместо неё выпадающий список `#navDd`) и панелью настроек (`.prefs`: выпадающие списки языка `#lang` и темы `#theme`, тема хранится в `localStorage['pf-theme']`), HUD, `<main class="stage">` с шестью `<section class="slide">`, шторка перехода, модалки проекта и сертификата, кастомный курсор.
- **JS** (IIFE в конце файла): `I18N` → `TEST DATA` → `KNOWLEDGE DATA` → геометрия шестерёнок и spin engine → фон (gears, circuits, binary) → `SLIDES & NAV` → `KNOWLEDGE GRAPH` → сертификаты → карусель проектов → модалки → форма → язык → `INIT`.

## Слайды

Это не прокручиваемая страница, а презентация. Слайды по порядку:
`0 about`, `1 experience`, `2 skills`, `3 certs`, `4 projects`, `5 contact`.

- Переход идёт через `goTo(i)`: кнопки пейджера внизу, клавиши, меню или любой элемент с `data-go="i"`. Индекс пишется в URL-хэш (`#projects`).
- Индексы слайдов зашиты в нескольких местах: `data-go`, ключи `nav.N` и `word.N`, статичные счётчики `ghost-num` в разметке, пункты меню в `#menu` и `#navDd`. Если добавляешь или переставляешь слайд, обнови все эти места.
- Меню — панель переключаемых кнопок. ≤1360px кнопки ужимаются, ≤1100px панель заменяется выпадающим списком слева. Добавляешь пункт — проверь ширину на 1101px на всех трёх языках (немецкий самый длинный).

## i18n: ru / en / de

- Весь видимый текст берётся из объекта `I18N` через атрибуты `data-i18n`, `data-i18n-aria` и `data-i18n-ph`. Текст прямо в разметке — только заглушка до первого `applyLang`.
- **Новый ключ добавляй сразу во все три языка.** Если ключа нет, `t()` берёт русскую версию, а если нет и её — показывает сам ключ.
- Выбранный язык хранится в `localStorage['pf-lang']`, по умолчанию берётся язык браузера, иначе `en`.

## Контент

- `CERTS` — настоящие данные, раздел сертификатов готов. Изображения лежат в `img/certs/`. Поля каждого сертификата:
  - `w`/`h` — размер картинки, по ним считаются ориентация и раскладка галереи;
  - `date` — `YYYY-MM-DD` или `YYYY-MM`, форматируется через `Intl` под язык сайта;
  - `verify` — ссылка на онлайн-проверку, если она есть;
  - название и описание — i18n-ключи `cert.<key>` и `cert.<key>.i`.
- Граф знаний (слайд `skills`) — черновик, собран по сертификатам и программе курса ITCareerHub/Beam «KI-Automatisierung»; владелец будет править. Данные в блоке `KNOWLEDGE DATA`:
  - `KN_CATS` — разделы в порядке таблицы. Цвет раздела — токен `--k-<key>` (RGB-тройка, задан в `:root` и в обоих тёмных блоках), название — `kn.cat.<key>`;
  - `KN_NODES` — узлы `{ id, cat, name?, hub? }`. `name` — подпись без перевода (названия технологий); без `name` подпись берётся из `kn.n.<id>` во всех трёх языках. `hub: true` — центральный узел раздела: подпись видна всегда и крупнее, в таблице идёт первым. Все узлы — одинаковые точки, размер зависит от числа связей;
  - `KN_LINKS` — строки `'a: b c d'`, связь двусторонняя. Опечатка в id — предупреждение в консоли. Размер узла и порядок в таблице зависят от числа связей;
  - раскладка — детерминированная симуляция при загрузке: все узлы лежат на поверхности сферы и равномерно отталкиваются друг от друга, связи слабо стягивают соседей, разделы тянутся к своим областям. При правке данных облако меняет форму, но при каждом открытии выглядит одинаково.
- Движок графа — canvas 2D со своей перспективной проекцией, без библиотек. Рисуется только когда слайд активен (`kgFrame` из главного цикла). Список в таблице и карточка узла строятся из данных через `innerHTML` с экранированием `esc()`.
- `JOBS` (слайд `experience`, таймлайн) — настоящие места работы по порядку: `{ key, name, parent?, logo?, icon?, from, now?, tags }`. `name`/`parent` — без перевода, описание — `job.<key>` во всех трёх языках, `from` — год начала (без него показывается заглушка `job.yyyy`). Логотип — файл в `img/logos/`; `icon` — ключ inline-иконки из `JOB_ICONS` в цветах темы (так сделан фриланс); без обоих — пустая пунктирная плашка. Знак AixPano — SVG с вшитым PNG, обрезанный `viewBox` и `clipPath` из вытянутого логотипа с их сайта. Заглушки: должность (`job.role`), технологии (`tags` — число плашек `job.tech`), описание фриланса (`job.freeD`).
  - Раскладка: на десктопе сетка 14 колонок, работа `i` начинается с колонки `2i+1` и занимает 4, чётные — над линией, нечётные — под ней; год стоит у узла на линии. ≤860px линия вертикальная по центру, карточки чередуются слева/справа (`--r`), год — внутри карточки. Добавишь седьмую работу — расширь сетку (`repeat(14,…)` → 16).
- `PROJECTS` — все семь проектов настоящие (drafta, Mira, Spirit FairPlate Shop, Benefita, Product Card AI, Gastronomie AI, Lingvy). Код для тестовых проектов без `key` (общие заглушки `proj.title`, `pm.*`) оставлен. У настоящего проекта есть `key` и `name` (название без перевода; если его нет, название берётся из `prj.<key>.t`), тексты берутся из ключей `prj.<key>.d` (карточка), `.lead`, `.p0`–`.p2` (вкладки модалки) и `.s<N>` (alt кадров) во всех трёх языках. `shots` — кадры `{ src, w, h, anim? }` из `img/projects/`: первый идёт в карточку, все вместе — в миниатюры модалки. `anim` — тяжёлый GIF: сначала показывается статичный `src`, а `playAnims()` подменяет его на анимацию, когда открыт слайд проектов или кадр в модалке (при `prefers-reduced-motion` остаётся статичный кадр). Клик по большому кадру в модалке открывает полноэкранный просмотр `#zoomer` (блок `SHOT ZOOM` в CSS и JS): зум колесом, кнопками, `+`/`-`/`0`, двойным кликом и щипком, перетаскивание, Esc закрывает только его. `url` — ссылка на живой проект, показывается кнопкой `pm.site` («Открыть сайт»). Метрики и кнопки демо/кода у настоящих проектов скрыты, пока для них нет данных; блок «Стек» скрыт, если `tags` пустой. Тестовые проекты берут общие заглушки (`proj.title`, `pm.*`).
- Фото в hero уже настоящее: `img/photo.jpg`. Кадрирование в круг задаётся через `object-position` в правиле `.photo img`.
- Видео в hero: `img/hero.mp4` (1920×1080, со звуком, `preload="none"`). Кнопка `#heroPlay` (продолговатая «как в YouTube», с выпуклыми верхом и низом — SVG-форма `#hpShape`) внизу налезает на край фото и пересекает кольцо делений; она лежит вне `.portrait-tilt`, чтобы 3D-наклон не перехватывал клик, а над ней кастомный курсор скрывается (класс `off`) и виден системный «палец». Пока видео играет, у `#portrait` класс `still`: spin engine плавно останавливает его шестерёнки (`s.host`), орбиты с цифрами на паузе, 3D-наклон выключен. Состояние кнопки переключается сразу, клик во время загрузки отменяет запуск. Кнопка запускает видео вместо аватара (`object-fit:cover`: по высоте целиком, бока обрезаются), повторное нажатие — пауза. По окончании или при уходе со слайда `about` (`heroVideoStop()` из `setActiveUI`) снова показывается аватар. Подписи — `hero.play` / `hero.pause`.
- Ещё заглушки: имя (`name.*`), статистика (`data-count`), медиа проектов. Контакты настоящие: `info@profidev.de`, Telegram `@a1exeych`, LinkedIn, Нюрнберг (в разметке слайда `contact`).
- Форма обратной связи (email, имя, фирма — необязательно, сообщение) шлёт JSON на `POST /api/contact`. Это Vercel Serverless Function `api/contact.js`: она пересылает сообщение в Telegram через Bot API. Нужны переменные окружения `TG_BOT_TOKEN` и `TG_CHAT_ID` в Vercel, в код их не класть. Скрытое поле `website` — ловушка для ботов (honeypot). Анимация отправки ждёт ответа сервера; при ошибке статус `f.err`. Под `python -m http.server` эндпоинта нет (ответ 501 → ошибка), для локальной проверки нужен `vercel dev`.

## Дизайн-конвенции

- Цвета — только токены `:root`. Тёмная тема задана **дважды**: `@media (prefers-color-scheme: dark)` и `:root[data-theme="dark"]`. Меняешь одну — меняй обе.
- Мотив шестерёнок: `data-gear="<зубья>"` рисует шестерёнку, `data-spin="<скорость>"` её вращает, `kick(el, deg)` и `boost(dir)` дают импульс.
- Анимация появления: обёртка с `data-a="up|left|right|scale|clip|fade"` и задержкой `style="--d:N"`.
- Учитывать `prefers-reduced-motion`: флаг `RM` в JS и отдельный media-блок в CSS.
- Не ломать навигацию с клавиатуры (стрелки, PageUp/Down, Home/End, Esc) и `aria-*` атрибуты.
- Колесо и свайп слайды **не** листают: они только прокручивают содержимое слайда и внутренние блоки, а по canvas графа свайп вращает облако. Горизонтальное колесо над каруселью проектов листает карточки.
- Листание — пейджер `#pager` в левом нижнем углу: кнопки `#pgPrev` / `#pgNext` с номером и названием соседнего слайда (`nav.N`) и стрелками влево / вправо. `setPager(i)` ставит им `data-go` и `aria-label` (`pg.prev` / `pg.next`), вызывается из `setActiveUI` и при смене языка. На первом и последнем слайде лишняя кнопка `disabled` и убрана (`display:none`). ≤520px пейджер растягивается по нижнему краю, номера скрыты, длинные названия обрезаются.
