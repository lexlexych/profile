# AGENTS.md

Сайт-портфолио разработчика ПО: автоматизация и AI-агенты. Весь сайт — один файл `index.html`.

## Стек и запуск

- Чистые HTML + CSS + vanilla JS в одном файле. Сборки, зависимостей, `package.json` и тестов нет.
- Внешнее только Google Fonts (Tektur, Onest, JetBrains Mono).
- Картинки лежат в `img/`.
- Запуск: `python -m http.server 8123`. Конфигурация для Claude Code — `.claude/launch.json`. Если открыть файл напрямую через `file://`, картинки по относительным путям могут не загрузиться. Проверять на ширине десктопа и 375px, в светлой и тёмной теме.
- Держать всё в одном файле. Фреймворки и сборку не вводить без запроса.

## Устройство `index.html`

Файл поделён комментариями-маркерами `/* ==== NAME ==== */`. Ищи по ним, номера строк быстро устаревают.

- **CSS**: `TOKENS` → фон → `NAV` → `HUD` → `STAGE / SLIDES` → по секции на каждый слайд → `SHUTTER TRANSITION` → `MODALS` → `RESPONSIVE` (1100 / 860 / 520px) → `CHATBOT`.
- **HTML**: шапка с меню и переключателем языка, HUD, `<main class="stage">` с пятью `<section class="slide">`, чат, шторка перехода, модалки проекта и сертификата, кастомный курсор.
- **JS** (IIFE в конце файла): `I18N` → `TEST DATA` → геометрия шестерёнок и spin engine → фон (gears, circuits, binary) → `SLIDES & NAV` → сертификаты → карусель проектов → модалки → форма → язык → чат-бот → `INIT`.

## Слайды

Это не прокручиваемая страница, а презентация. Слайды по порядку:
`0 about`, `1 journey`, `2 certs`, `3 projects`, `4 contact`.

- Переход идёт через `goTo(i)`: колесо, свайп, клавиши или любой элемент с `data-go="i"`. Индекс пишется в URL-хэш (`#projects`).
- Индексы слайдов зашиты в нескольких местах: `data-go`, ключи `nav.N` и `word.N`, правила в `fallbackAnswer`, секции в `buildPrompt`, статичные счётчики `0X / 05` в разметке. Если добавляешь или переставляешь слайд, обнови все эти места.

## i18n: ru / en / de

- Весь видимый текст берётся из объекта `I18N` через атрибуты `data-i18n`, `data-i18n-aria` и `data-i18n-ph`. Текст прямо в разметке — только заглушка до первого `applyLang`.
- **Новый ключ добавляй сразу во все три языка.** Если ключа нет, `t()` берёт русскую версию, а если нет и её — показывает сам ключ.
- Выбранный язык хранится в `localStorage['pf-lang']`, по умолчанию берётся язык браузера, иначе `en`.

## Контент

- `CERTS` — настоящие данные, раздел сертификатов готов. Изображения лежат в `img/certs/`. Поля каждого сертификата:
  - `w`/`h` — размер картинки, по ним считаются ориентация и раскладка галереи;
  - `date` — `YYYY-MM-DD` или `YYYY-MM`, форматируется через `Intl` под язык сайта;
  - `verify` — ссылка на онлайн-проверку, если она есть;
  - название и описание — i18n-ключи `cert.<key>` и `cert.<key>.i`.
- `PROJECTS`, `JOBS` — тестовые данные. Названия и описания подставляются геттерами из общих i18n-ключей (`proj.title`, `cert.title`, `job.role` и т.д.). Для настоящего контента нужны свои поля или ключи на каждый элемент.
- Фото в hero уже настоящее: `img/photo.jpg`. Кадрирование в круг задаётся через `object-position` в правиле `.photo img`.
- Ещё заглушки: имя (`name.*`), статистика (`data-count`), `hello@example.com` (в разметке, в `fb.contact` на трёх языках и в `buildPrompt`), `@username`, ссылки соцсетей (`href="#"`), медиа проектов.
- Форма контакта — демо: валидирует и проигрывает анимацию, но никуда не отправляет данные.

## Чат-бот

- Если есть `window.claude.use('sample')` (среда Claude Artifacts), отвечает LLM. Иначе работает демо-режим: `fallbackAnswer` подбирает готовый ответ регулярками.
- Системный промпт в `buildPrompt()` запрещает выдумывать факты, пока контент — заглушки. Когда появится реальный контент, обнови промпт.
- На обычном хостинге AI-режима не будет, для него нужен свой бэкенд или прокси к LLM API. Ключи API в клиентский код не класть.
- Сообщения пользователя выводятся только через `textContent`, не через `innerHTML`.

## Дизайн-конвенции

- Цвета — только токены `:root`. Тёмная тема задана **дважды**: `@media (prefers-color-scheme: dark)` и `:root[data-theme="dark"]`. Меняешь одну — меняй обе.
- Мотив шестерёнок: `data-gear="<зубья>"` рисует шестерёнку, `data-spin="<скорость>"` её вращает, `kick(el, deg)` и `boost(dir)` дают импульс.
- Анимация появления: обёртка с `data-a="up|left|right|scale|clip|fade"` и задержкой `style="--d:N"`.
- Учитывать `prefers-reduced-motion`: флаг `RM` в JS и отдельный media-блок в CSS.
- Не ломать навигацию с клавиатуры (стрелки, PageUp/Down, Home/End, Esc) и `aria-*` атрибуты.
